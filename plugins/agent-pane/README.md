# agent-pane

セッション内のサブエージェントの状況を一覧するペインを追加する mod。
スキルではなく、Claude Code の表示を変える hooks モジュールである。

## インストール

```
/plugin marketplace add swallowarc/swallowarc-ai-plugins
/plugin install agent-pane@swallowarc-ai-plugins
```

インストールすると、そのセッションから有効になる。

## 使い方

サブエージェントが起動すると、ペインが自動で開く。
端末の幅が 144 桁に満たない場合は自動では開かないので、コマンドで開く。

```
/agent-pane
```

このコマンドは開閉の切り替えで、開いているときに実行すると閉じる。
閉じても記録は残り、もう一度実行すれば同じ内容が出る。

## 表示内容

実行中のエージェントは、直近のツール呼び出しを最大 3 件と、書き込んだファイルを出す。

```
● general-purpose Fix the failing test
  8s · 3 tools · ctx 38.6k (19%) · fable-5-2
  · Read: /src/app.test.ts
  · Edit: /src/app.ts
  ▸ Bash: npm test
  ✎ 1 file · app.ts
```

完了すると、ツール呼び出しの行が最終報告の冒頭（最大 4 行）に変わる。

```
✓ general-purpose Fix the failing test
  23s · 7 tools · ctx 41.1k (21%) · fable-5-2
  ⎿ The test failed because the fixture was stale. I regenerated it and …
  ✎ 2 files · fixture.json, app.ts
```

- 先頭のマークは状態を表す。
  `●` は実行中、`✓` は完了、`✗` は中断またはエラーである。
- 2 行目は、経過時間、ツール呼び出しの回数、コンテキストサイズと使用率、モデルである。
- `▸` は直近のツール呼び出し、`·` はその前の呼び出しである。
- `✎` は Edit、Write、NotebookEdit で書き込んだファイルの件数と名前で、新しい順に並べる。
- 実行中のエージェントを上に、完了したものを新しい順に並べる。
  ペインの高さに入りきらない分は `… n more` にまとめる。

## 表示の仕様と制約

- `ctx` は、そのエージェントの直近のモデルリクエストで API が報告した入力と出力の合計である。
  累計の消費量ではないので、課金額の目安にはならない。
- 使用率は、エージェントのモデルがメインの会話と同じときだけ出す。
  エンジンから取れるウィンドウの大きさがメインのモデルの分だけだからである。
  エージェントに個別の圧縮しきい値が設定されていても、それは反映しない。
- 書き込んだファイルは、ファイルを書くツールの呼び出しから拾う。
  Bash 経由の書き込みは拾えず、呼び出しが拒否または失敗した場合も数に入る。
- 費用は出さない。
  ステータスラインと `/cost` の金額が、サブエージェントの分を含むセッション全体の合計だからである。
- 記録はセッション単位で、最大 50 件まで保持する。
- コンテキストサイズを取るために、メインの会話を含む全モデルリクエストを通過するフックを置いている。
  メインの会話のリクエストには手を加えない。

## 前提

mod の API は early access であり、Claude Code のバージョンによって変わる。
作成時のバージョンは 2.1.322 で、それより古いバージョンや大きく離れたバージョンでは動かない可能性がある。
読み込みに失敗した場合は、`claude --debug` のログに理由が出る。
