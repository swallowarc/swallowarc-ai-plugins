# yosooi

ターミナルの Claude Code のトランスクリプトを装い直す mod。
スキルではなく、Claude Code の表示を変える hooks モジュールである。

## インストール

```
/plugin marketplace add swallowarc/swallowarc-ai-plugins
/plugin install yosooi@swallowarc-ai-plugins
```

インストールすると、そのセッションから有効になる。

## 表示内容

```
 ❯ YOU  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━╍╍╍┅┅┅┉┉┉

❯ README.md の先頭を読んで

●  READ  …/swallowarc-ai-plugins/README.md

 ✦ CLAUDE  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━╍╍╍┅┅┅┉┉┉

⏺ 読みました。
┉┉┉┅┅┅╍╍╍━━━━━━━━━━━━━━ ✦ Brewed for 5s ━━━━━━━━━━━━━━╍╍╍┅┅┅┉┉┉
```

- **発言の見出し**: 自分のプロンプトと Claude の返答の先頭に、チップとグラデーションの罫線を置く。
  本文はエンジンの描画をそのまま使う。
- **ツール行**: Bash、Read、Grep、Glob、Edit、Write、NotebookEdit、WebFetch、WebSearch、ToolSearch、Skill、MCP ツールを、色付きのチップと 1 行の要約で描く。
  チップの色は実行・読み取り・書き込み・その他で分かれる。
  行頭の印は実行中が `◌`、成功が `●`、失敗が `✗`、中断が `⊘` である。
- **まとめ行**: 連続するツール呼び出しのまとめ行を、ツールごとの件数チップで描く。
- **スピナー**: エンジンの行（語、経過時間、トークン数）の左に、グラデーションの彗星を流す。
- **ターンの区切り**: `Baked for 3s` の行を、画面幅の罫線にする。

## 配色の切り替え

```
/yosooi            現在の配色と選択肢を表示する
/yosooi akane      配色を切り替える
/yosooi off        mod の描画を止め、エンジンの表示に戻す
```

| 名前 | 色合い |
| --- | --- |
| `neon` | マゼンタ → 紫 → シアン（既定） |
| `akane` | 黄 → 橙 → 紅 |
| `wakaba` | 若草 → 緑 → 青緑 |
| `koori` | 白 → 水色 → 藍 |

選んだ配色はセッションをまたいで保存される。

## 仕様と制約

- 描くのはターミナルだけである。
  デスクトップアプリ、VS Code、モバイルではエンジンの表示のままになる。
- 色は 24bit の直値で指定している。
  truecolor に対応しないターミナルでは近い色に丸められ、グラデーションが段になる。
- ターミナル自体の背景色と文字色は変えない。
  明るい背景のターミナルでは `koori` の淡い色が見えにくい。
- 見出しは 1 回の発言につき 2 行（空行と見出し）を使う。
- Agent、AskUserQuestion、プランなど、上に挙げていないツールの行はエンジンの表示のままである。
  詳細表示（ctrl+o）でも、すべての行がエンジンの表示に戻る。
- 権限プロンプト、入力欄、ロゴには手を入れない。
- ツール行とまとめ行をこの mod が描くため、同じ行に描き足す他の mod（`bash-meter` など）とは、読み込み順によって表示が変わる。
- スピナーの彗星は 150ms ごとに描き直す。
  スピナーが画面から消えると、2 秒以内にタイマーを止める。

## 前提

mod の API は early access であり、Claude Code のバージョンによって変わる。
作成時のバージョンは 2.1.328 で、それより古いバージョンや大きく離れたバージョンでは動かない可能性がある。
読み込みに失敗した場合は、`claude --debug` のログに理由が出る。
